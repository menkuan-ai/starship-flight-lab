# Starship Flight Lab

[在线体验](https://menkuan-ai.github.io/starship-flight-lab/) · [Windows 下载](https://github.com/menkuan-ai/starship-flight-lab/releases/latest)

星舰工程观察与真实尺度航天任务模拟。浏览器支持 WebGL2，需要最新版 Edge / Chrome，首次加载精密模型需要时间。玩家无需密码。Windows 包为独立 WebView2 窗口。

操作：左键旋转，中键平移，滚轮缩放；任务中选择发射方位，点击启动任务，按下一关键阶段加速。软件顶部提供完整简介和简明教程。

独立作品，非 SpaceX 官方软件；上级双臂捕获及未公开内部/性能为标明的工程近似。第三方署名和许可在游戏依据页面及 Windows Licenses 目录。
