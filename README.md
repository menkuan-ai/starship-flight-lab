# Starship Flight Lab

由 GPT 制作的独立星舰工程观察与航天任务模拟作品。

[项目与下载](https://menkuan-ai.github.io/starship-flight-lab/) · [Windows 下载](https://github.com/menkuan-ai/starship-flight-lab/releases/tag/windows-r12)

下载 Starship-Windows.zip，完整解压后双击 Starship Flight Lab.exe。玩家无需密码。需要 Windows 10/11 x64、.NET Framework 4.8、微软 WebView2 和支持 WebGL2 的显卡。

工程观察室：左键旋转、中键平移、滚轮缩放；任务模拟：选择发射方位，启动任务，通过“推进到下一关键阶段”加速。简介和教程可在软件顶部打开。

支持精密模型、360°方位发射、独立卫星、轨道编辑、稳定轨道存档与多轮任务。非 SpaceX 官方软件；未验证的上级塔架捕获及未公开参数为明确标注的工程近似。第三方许可和署名随软件保留。
